策略选择逻辑

选择率由倒排表精确基数 + 数值列分位数估计, 阈值可在构建参数中调整:

graph_filtered 选择率 > 5%: 图搜索中跳过不满足的节点, 但仍然经过它们继续走, 连通性不受影响。

graph_relaxed 0.5% ~ 5%: 放大候选队列 ef×4 对抗命中稀释; 图结果不足 K 时用倒排枚举子集补搜。

brute_force 选择率 ≤ 0.5%: 直接在满足条件的子集上暴力(倒排交集枚举), 避免图搜索的空转开销。
